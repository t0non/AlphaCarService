# **App Name**: GearUp Garage

## Core Features:

- WhatsApp Integration: Enable instant estimate requests and updates via WhatsApp, including image and video sharing for issue diagnosis.
- AI-Powered Defect Diagnostic Tool: Utilize generative AI to suggest potential causes and solutions based on user-provided symptom descriptions and uploaded media. The generative AI tool will consider make/model details, common failure points and reported symptoms to identify likely root causes and prioritize troubleshooting steps for mechanic's review.
- Service Showcase: Visually rich displays for detailing preventative maintenance, brake & suspension work, electronic injection and oil change offerings
- Customer Testimonials Display: Display genuine customer reviews and WhatsApp conversation snippets.
- Location and Contact Info: Show shop address, phone, hours, and a link to Waze/Maps.
- Appointment Scheduling: Implement a booking system for service appointments.

## Style Guidelines:

- Primary color: Dark gray (#333333) to convey professionalism and reliability.
- Background color: Light gray (#f2f2f2), providing a clean and modern look.
- Accent color: Medium gray (#808080), subtly highlights call to action buttons.
- Body and headline font: 'Roboto', sans-serif for a modern and readable look.
- Code font: 'Source Code Pro' for displaying technical snippets or diagnostic codes, if necessary.
- Use clean and simple icons in a monochromatic style to represent services.
- Employ subtle transitions and animations for loading content and displaying testimonials.
